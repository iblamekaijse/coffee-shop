# СЛОЙ — авторская кофейня

Рабочая одностраничная витрина напитков и выпечки на Vite, React, TypeScript и CSS.

## Запуск

```bash
npm install
npm run dev
```

Открой адрес, который выведет Vite (обычно http://localhost:5173).

Проверка сборки: `npm run build`. Проверки интерфейса (при наличии браузеров Playwright): `npm run test:e2e`.

## Управление

- Перетаскивание мышью или горизонтальный свайп для выбора напитка.
- Стрелки под витриной, точки и нажатие на бокал.
- При фокусе на витрине работают клавиши ← и →.
- В секции выпечки есть стрелки и индикаторы трёх позиций.
- Якоря шапки ведут к трём разделам. На мобильных вертикальная прокрутка не блокируется.

## Изображения

Все изображения находятся в `public/images/` в оптимизированном формате WebP. 8 предметных изображений напитков были созданы для проекта и отделены на прозрачном фоне. Изображения выпечки и ингредиентов подготовлены из оригинальных сгенерированных предметных сцен. Меню централизовано в `src/catalog.ts`.

Примечание: кофейня вымышленная; сайт не содержит вымышленных адресов, телефонов или онлайн-оплаты.
